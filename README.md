# AI Neuro Monitor

Multi-component research project for physiological and neurological 
signal processing and stress detection.

## Components

| Folder | Component | Description |
|---|---|---|
| physiological_signals/ | Stress Detection | HRV + GSR based perceived stress detection |
| eeg/ | EEG Processing | EEG signal analysis |
| phenotyping/ | Phenotyping | Behavioural phenotyping |
| relaxation_guide/ | Relaxation Guide | Stress intervention and guidance |

## Repository Rules

- Each member works only inside their own component folder
- Common files (this README, .gitignore) are at root level
- Never commit datasets or virtual environments
- Each component has its own requirements.txt and virtual environment
